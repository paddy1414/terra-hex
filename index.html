Host Terra Hex on CubeCoders AMP

Generic Module • Node.js Game & Multiplayer Server

You can host Terra Hex directly on your CubeCoders AMP panel using AMP's Generic Application template. Click below to download a ready-to-upload standalone Node.js server file (server.js) paired with this game client.

Step-by-Step CubeCoders AMP Setup
  1. In AMP, click Create Instance and select the Generic Module (or Node.js template).
  2. Open the instance's File Manager and upload index.html and server.js into the root directory.
  3. In AMP Configuration → Generic Settings, set:
    Executable: /usr/bin/node
    Arguments: server.js --port {{$ApplicationPort1}}
    Application Port 1: 7779 (TCP)
  4. Click Start in AMP and share http://YOUR-SERVER-IP:7779 with your friends!
